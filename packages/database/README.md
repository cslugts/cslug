# @cslug/database

PostgreSQL on `Bun.sql`, with no ORM: typed tables, the `sql` tag, ambient transactions and advisory locks, a
query builder, repositories, `preload`, SQL-file migrations, factories, seeders, `idempotent()` and encrypted
columns.

Part of [cslug](https://github.com/cslugts/cslug). Docs: [docs/README.md](docs/README.md), [docs/api.md](docs/api.md),
[guide 09](../../guides/09-database.md).
