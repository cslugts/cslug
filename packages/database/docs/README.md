# @cslug/database

PostgreSQL on `Bun.sql`, with no ORM and no dependency. Typed tables, the `sql` tag, ambient transactions and
advisory locks. (Query builder, repositories, migrations and factories come in the next M2 steps.)

```ts
import { amount, currency, date, id, sql, table, text, timestamps, type Row } from '@cslug/database'

export const bookings = table('bookings', {
  id: id(),                                            // UUIDv7, generated by the app
  status: text().oneOf(['requested', 'deposit_paid']).default('requested'),
  startDate: date(),                                   // 'YYYY-MM-DD'
  currency: currency(),
  deposit: amount(),                                   // bigint minor units
  ...timestamps(),
})
export type Booking = Row<typeof bookings>

await db.transaction(async () => {
  const booking = await db.one(sql`select * from ${bookings} where ${bookings.c.id} = ${id} for update`, bookings)
  await db.exec(sql`update ${bookings} set status = 'deposit_paid' where ${bookings.c.id} = ${id}`)
  await SendReceiptJob.dispatch({ bookingId: id })     // sent only after COMMIT
})
```
