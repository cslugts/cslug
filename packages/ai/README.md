# @cslug/ai

Agents and tools as `@inject()` classes, structured output validated by `v` schemas, prompts as Markdown files,
streaming to the browser with `sse()`, Anthropic and OpenAI-compatible providers over `fetch`, and a test fake.
`cslug add ai` installs it and adds `AiProvider`.

Part of [cslug](https://github.com/cslugts/cslug). Docs: [docs/README.md](docs/README.md), [docs/api.md](docs/api.md),
[guide 18](../../guides/18-ai.md).
