# @cslug/redis

Redis connections through `Bun.redis`, and Redis drivers for core's `Cache`, `Lock`, `RateLimiter` and
`SessionStore`. List `RedisProvider` in `bootstrap/providers.ts`.

Part of [cslug](https://github.com/cslugts/cslug). Docs: [docs/README.md](docs/README.md), [docs/api.md](docs/api.md),
[guide 10](../../guides/10-cache.md).
