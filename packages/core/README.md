# @cslug/core

The application, the container with standard `@inject(A, B)`, service providers, the ambient context, config and
env validation, typed errors, `Clock`, `Money`, events, the logger, i18n, and the `Cache`/`Lock`/`RateLimiter`/
`SessionStore` contracts with in-memory drivers.

Part of [cslug](https://github.com/cslugts/cslug). Docs: [docs/README.md](docs/README.md), [docs/api.md](docs/api.md),
guides [02](../../guides/02-container-and-di.md), [03](../../guides/03-service-providers.md),
[04](../../guides/04-configuration.md), [13](../../guides/13-events.md), [16](../../guides/16-i18n.md).
