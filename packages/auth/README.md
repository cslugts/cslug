# @cslug/auth

Session and token authentication (`ctx.auth`), password hashing, magic links, API tokens, policies and gates.
List `AuthProvider` in `bootstrap/providers.ts` and set `config/auth.ts` → `users`.

Part of [cslug](https://github.com/cslugts/cslug). Docs: [docs/README.md](docs/README.md), [docs/api.md](docs/api.md),
[guide 15](../../guides/15-auth-and-authorization.md).
