# Conventions

## Naming

| Thing | Convention | Example |
|---|---|---|
| Files & folders | kebab-case; file = class name, role last; grouped by type (`app/validators/`) | `store-booking-validator.ts` |
| Classes | PascalCase, suffix matches role | `StoreBookingValidator`, `SendCheckinJob` |
| Methods, variables, TS properties | camelCase | `depositAmount` |
| DB tables & columns | snake_case, tables plural | `bookings.deposit_amount` (mapped to `depositAmount` automatically) |
| URLs | kebab-case, plural resources | `/trip-requests/:tripRequest` |
| Route names | dot.case | `bookings.show`, `admin.operators.verify` |
| Events | dot.case, past tense | `booking.deposit_paid` |
| Translation keys | dot.case, namespaced by domain | `bookings.created`, `validation.required` |
| Error codes | dot.case | `booking.invalid_transition` |
| Queues | kebab-case | `default`, `notifications`, `payments` |
| Env vars | SCREAMING_SNAKE | `DATABASE_URL`, `REDIS_URL` |

## Code

- TypeScript `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `verbatimModuleSyntax`.
- ES modules only; subpath aliases (`#app/*`) instead of deep relative imports.
- Never `throw new Error('...')` in framework or app code — use a typed error.
- Never `process.env` outside `config/env.ts`; use `config()`.
- Never `new Date()` / `Date.now()` in domain code; inject `Clock` (tests control time).
- DI uses **standard decorators** (no `experimentalDecorators`): `@inject(A, B)` lists the constructor's
  dependencies in order, and `tsc` rejects a list that does not match the constructor.
- Biome for lint + format.

## Money

- Stored as `bigint` **minor units** in `amount()` columns, next to a `char(3)` ISO 4217 `currency()` column.
  A row whose amounts share a currency (a booking: total, deposit, commission) has one currency column.
- In TypeScript: the `Money` value object (`Money.of(220000n, 'EUR')`), immutable, with `add`, `subtract`,
  `percent(8)`, `allocate([30, 40, 30])` (no lost cents), `format(locale)`.
- Validated with `v.money()` / `v.amount()`; bigints are serialized to the client as strings (`"220000"`)
  because JSON has no bigint. Island props and JSON responses use `Serialized<Row>` (bigint → string,
  Date → ISO string) to type this exactly. Views (`*.vue`) receive real rows, because they only run on the server.
- Floats for money are a lint error.

## Identifiers

- Primary keys: UUIDv7 (`id()`), generated by the app (`Bun.randomUUIDv7()`), so IDs exist before insert and
  index locality is good.
- Public references shown to people (booking reference, claim number): a separate short code column
  (`ref: shortCode('ALB')` → `ALB-7K2Q9F`).

## Time

- All timestamps `timestamptz`, stored and computed in UTC.
- Converted to a time zone only for display (`formatDate(d, { tz: 'Indian/Antananarivo' })`) or for schedules
  (`.timezone('Indian/Antananarivo')`).
- Dates without time (trip start date) are `date` columns and `Temporal.PlainDate`-like strings (`'2027-05-14'`)
  in TS — never a `Date` at midnight.
- Domain code reads time from the injectable **`Clock`** (`@cslug/core`), which tests control:

  | Method | Returns |
  |---|---|
  | `now()` | `Date` (UTC instant) |
  | `today(offsetDays = 0, tz = config('app.timezone'))` | `'YYYY-MM-DD'` |
  | `add(duration)` / `subtract(duration)` | `Date` relative to now (`'90d'`, `'2h'`, `'15m'`) |
  | `atLocal(date, time, tz)` | `Date` for a local wall-clock time, e.g. 07:00 in Antananarivo on a trip date |

## Errors returned to clients

APIs: RFC 9457 `application/problem+json`:

```json
{
  "type": "https://albastr.com/errors/booking.invalid_transition",
  "title": "This booking cannot move from deposit_paid to completed.",
  "status": 409,
  "code": "booking.invalid_transition",
  "requestId": "01JD…"
}
```

Validation (422) adds `"errors": { "groupSize": ["Must be at most 12."] }`. HTML form posts get the same
errors in the session (redirect back with old input) instead of JSON (see [guides/07](../guides/07-validation.md)).

## Tests

- File next to the flow: `tests/feature/bookings/release-deposit.test.ts`.
- Each feature test runs in a rolled-back transaction; fakes for queue, mail, notifications, storage, clock.
- A bug fix starts with a failing test.
